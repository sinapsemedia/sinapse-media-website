# SINAPSE MEDIA

Website de prezentare pentru SINAPSE MEDIA.

## Publicare

Proiectul este configurat pentru publicare automată prin GitHub Pages din branch-ul `main`, folosind workflow-ul din `.github/workflows/deploy.yml`.

## Fișiere principale

- `index.html` — structura paginii și conținutul
- `styles.css` — design responsiv și stilurile vizuale
- `script.js` — interacțiuni pentru navigarea mobilă
- `vercel.json` — configurare alternativă pentru hosting Vercel
